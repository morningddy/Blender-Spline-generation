# 样条线生成器 (Spline Object Generator)

Blender 插件，沿曲线/样条线自动生成物体，支持多实例、多段样条线分段处理、头尾模型、随机变换等功能。

## 安装

1. 下载插件：`spline_object_generator.py`
2. 打开 Blender → 编辑 → 偏好设置 → 插件
3. 点击右上角「从磁盘安装...」，选择 `spline_object_generator.py`
4. 在侧边栏（N键）「样条线生成」面板中使用

或在另一台电脑直接 clone 本仓库，把 `spline_object_generator.py` 放入 Blender 插件目录：
```
git clone https://github.com/morningddy/Blender-Spline-generation.git
# 将 spline_object_generator.py 复制到 Blender 插件目录后启用
```

## 功能特性

- **多实例**：场景内可创建多个生成器，每个独立控制
- **多段样条线**：同一条曲线对象内的多个样条线/Spline 分段处理
- **三种模式**：
  - 单个物体：整个样条线用同一个物体
  - 多个物体：可指定循环体列表，HEADTAIL 模式可分别设置头/尾/循环体
- **头尾模型**：HEADTAIL 模式下头部和尾部使用独立模型，位置固定
- **三轴独立缩放**：头部缩放、尾部缩放、基础缩放均支持 X/Y/Z 独立控制
- **随机变换**：随机旋转、随机缩放（统一/独立）
- **绑定曲线**：开启后曲线移动/旋转/缩放时生成物实时跟随
- **填满样条线**：自动按源物体尺寸计算间距，紧密排列摆满
- **偏移控制**：头尾模型和循环体可独立设置位置偏移

## 使用方法

1. 在侧边栏「样条线生成」面板，点击「添加生成器」
2. 在「目标曲线」中添加要生成的曲线对象
3. 选择模式，添加源物体（循环体 / 头尾模型）
4. 调整分布设置（数量、间距、偏移等）
5. 点击「生成」，或开启「自动更新」实时预览

## 注意事项

- 曲线对象需要先转换为网格才能采样（插件内部自动处理）
- 绑定曲线模式下，移动/旋转/缩放曲线对象会触发生成物更新
- 头尾偏移值为百分比（0~1），表示沿曲线的位置比例
