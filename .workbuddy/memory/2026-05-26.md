## 样条线生成器插件
- 创建了 Blender 插件 `spline_object_generator.py`
- 功能：沿贝塞尔曲线/样条线批量生成选中的物体
- 支持模式：单一物体复制、多个物体循环/随机/首尾模型排列
- 分布方式：按数量 + 按间距（间距=0 则均匀分布，间距>0 则按固定距离排列）
- 旋转：跟随曲线方向 + 随机旋转
- 缩放：基础缩放倍率 + 等比/非等比随机缩放
- 克隆：关联复制（Alt+D）/ 独立复制
- UI：3D视图侧边栏 "样条线生成" 面板
- 另含 Object 菜单入口

### v1.1 更新 (21:24)
- 添加 `base_scale` 基础缩放属性，对所有生成物体统一缩放

  - 间距=0：沿曲线均匀分布 count 个物体
  - 间距>0：按固定距离排列，最多 count 个（受曲线长度限制）

## v1.6 更新 (23:30) — 分组偏移

### 需求
用户要求「偏移里面每个模型偏移的不一样要分头尾模型和循环模型」，
即头部模型、尾部模型、循环体各自有独立的偏移设置。

### 新增属性（SplineGenProperties）

| 属性 | 说明 |
|---|---|
| `head_use_offset` | 头部模型是否启用偏移 |
| `head_offset_axis` | 头部偏移轴（LOCX/LOCY/LOCZ/NORMAL） |
| `head_offset_distance` | 头部偏移距离 |
| `tail_use_offset` | 尾部模型是否启用偏移 |
| `tail_offset_axis` | 尾部偏移轴 |
| `tail_offset_distance` | 尾部偏移距离 |
| `loop_use_offset` | 循环体是否启用偏移 |
| `loop_offset_axis` | 循环体偏移轴 |
| `loop_offset_distance` | 循环体偏移距离 |

### 逻辑修改（`_place_objects`）

在偏移步骤中根据当前模型类型选择对应设置：
```python
is_head = (has_headtail and i == 0 and props.head_object is not None)
is_tail = (has_headtail and i == len(points)-1 and props.tail_object is not None)
is_loop = not (is_head or is_tail)

if is_head and props.head_use_offset:
    off_axis = props.head_offset_axis
    off_dist = props.head_offset_distance
elif is_tail and props.tail_use_offset:
    ...
elif is_loop and props.loop_use_offset:
    ...
elif not has_headtail and props.use_offset:
    # 非 HEADTAIL 模式用全局偏移
    ...
```

### UI 修改

HEADTAIL 模式下偏移面板显示三组独立控件：
- 「头部模型偏移」→ head_use_offset / head_offset_axis / head_offset_distance
- 「尾部模型偏移」→ tail_use_offset / tail_offset_axis / tail_offset_distance
- 「循环体偏移」  → loop_use_offset / loop_offset_axis / loop_offset_distance

非 HEADTAIL 模式保持原来的全局偏移控件不变。

## v1.7 更新 (23:36) — 偏移改为三轴数值输入

### 需求
用户要求偏移不要选择轴下拉菜单，直接改成三个轴（X/Y/Z）分别输入数字，
参考 Blender 位置属性的样式（位置 X / Y / Z，每行一个数值）。

### 改动

**属性定义替换（SplineGenProperties）**
- `offset_axis` (Enum) + `offset_distance` (Float) → `offset_x` / `offset_y` / `offset_z` (Float)
- `head_offset_axis` + `head_offset_distance` → `head_offset_x` / `head_offset_y` / `head_offset_z`
- `tail_offset_axis` + `tail_offset_distance` → `tail_offset_x` / `tail_offset_y` / `tail_offset_z`
- `loop_offset_axis` + `loop_offset_distance` → `loop_offset_x` / `loop_offset_y` / `loop_offset_z`

**逻辑修改（`_place_objects`）**
```python
# 原逻辑：根据 axis + distance 构造局部向量
local_vec = Vector((off_dist, 0, 0))  # 或 Y、Z、NORMAL

# 新逻辑：直接用三个轴的值构造局部向量
local_vec = Vector((off_x, off_y, off_z))
offset_vec = final_quat @ local_vec  # 转到世界空间
```
移除了 `NORMAL`（曲线法线）偏移模式，现在通过组合 XYZ 值即可实现任意方向偏移。

**UI 修改**
- HEADTAIL 模式每组偏移启用后显示 X/Y/Z 三个数值输入框
- 非 HEADTAIL 模式全局偏移同样显示 X/Y/Z 三个数值输入框
- 类似 Blender 位置属性面板样式

- AST 语法检查：PASSED
